Exercício 2 — Construção da Representação Semântica com FastText + Mean Pooling

Técnica: Embeddings + FastText + Mean Pooling

Missão: Transformar mensagens de texto em vetores numéricos densos capazes de representar, de forma aproximada, o significado das mensagens.

No Exercício 1, você construiu a primeira etapa do pipeline de NLU: a normalização do texto. Agora, o desafio é construir a segunda etapa.

O computador ainda não consegue utilizar diretamente uma mensagem como: "quero devolver meu sofá". Precisamos transformá-la em uma representação numérica.

Para isso, você utilizará FastText, que representa palavras por meio de vetores densos, e depois aplicará Mean Pooling para transformar vários vetores de palavras em um único vetor que represente a mensagem inteira.

Utilizaremos um modelo FastText treinado durante a própria atividade.

Isso é importante porque o objetivo não é apenas utilizar um modelo pronto, mas compreender como uma representação baseada em subpalavras pode ser utilizada para construir um sistema de NLU.

Utilize:

from gensim.models import FastText

modelo_fasttext = FastText(
    sentences=corpus_tokenizado,
    vector_size=50,
    window=3,
    min_count=1,
    workers=4,
    sg=1
)

O parâmetro: vector_size=50, define que cada palavra será representada por um vetor com 50 dimensões.

O FastText possui uma característica particularmente importante: ele utiliza informações de subpalavras. Isso permite que palavras semelhantes ou pequenas variações tenham representações relacionadas.

Primeiro, você deverá utilizar o dataset: sac_moveis_ac2.csv

A coluna "mensagem", será utilizada como corpus para construção dos embeddings.
